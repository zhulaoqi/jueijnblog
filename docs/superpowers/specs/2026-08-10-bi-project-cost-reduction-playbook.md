# BI 组项目资源盘点与降本作战手册

> **文档用途**：统一降本定调、数据口径与执行模板，赋能组员按服务推进清理与优化。  
> **数据状态**：框架已就绪，数字位待填。先按「数据收集清单」补齐，再填总览矩阵与服务评估卡。  
> **目标区间**：月成本下降 **15%–30%**（摸底后收紧为正式目标）。  
> **范围**：生产 + 预发/测试；集群内（Pod/节点）+ 集群外（ECS / RDS / Redis / LB / 磁盘等）。  
> **排序原则**：算力 + 存储 + 网络全量纳入；**先按风险等级（P0→P2），同级内再按浪费金额**排序。

## 0. 一页定调

### 0.1 任务目标

| 项 | 内容 |
|----|------|
| 业务目标 | IT 成本降本增效，清理多余与不合理资源 |
| 量化目标（初） | 月成本下降 15%–30%（区间参考，用于排期与对焦） |
| 量化目标（终） | **W2 结束前**用总览矩阵「可砍空间」提出候选正式目标；**月末收口会**由牵头人签字冻结 |
| 交付物 | 服务级评估结论 + 可执行优化动作 + 节约金额跟踪 |

**目标冻结规则**

| 节点 | 做什么 | 用途 |
|------|--------|------|
| D7 | 冻结**基线月成本**（见 §1.3） | 计算区间上下轨 |
| W2 末 | 公布**候选正式目标**（金额） | 周报进度暂用此数 |
| 月末收口 | **冻结正式目标**（可等于或微调候选值） | 对外达成口径以此为准；冻结后原则上不回溯改基线 |

### 0.2 原则

1. **先证据后动作**：无约定类型的证据，不关不停不降配（证据类型见 §5.0）。
2. **先低风险后高风险**：闲置测试机 / 无业务用途实例优先于生产缩容。
3. **同风险等级内按浪费金额排序**：月浪费更大者优先。
4. **归因清楚再计节约**：「归属待确认」不得计入已达成节约；共享中间件节约只在中间件卡上计一次。
5. **可回滚才动生产**：无回滚方案、无观察窗口，生产默认不动。

### 0.3 红线

- 生产变更无回滚方案 → 禁止执行
- 「已知例外清单」内资源 → 禁止擅自关停
- 仅凭主观判断「感觉闲」、无 §5.0 约定证据 → 禁止关停/降配
- 将「归属待确认」计入达成 → 禁止
- 影响查询/任务主链路的变更 → 必须先 staging 验证，再 prod，观察窗口建议 ≥ 24h

### 0.4 时间盒

| 阶段 | 时间 | 产出 |
|------|------|------|
| 启动 | D1–D2 | 手册发布、Owner 认领、例外清单冻结 |
| 取数 | D3–D7 | 最低可开工包齐备，总览矩阵初版，**基线月成本冻结** |
| P0 | 第 1–2 周 | 符合 P0 证据门槛的关停/清挂账；出首批**已确认**节约 |
| 校准 | W2 末 | 监控补齐后校准 P1；公布**候选正式目标** |
| P1 | 第 2–3 周 | 缩容、降规格、测试定时开关机 |
| P2 | 第 4 周起 | 付费优化、合并、节点池整理（需评审） |
| 收口 | 月末 | **冻结正式目标**，复盘缺口与未完成项 |

## 1. 盘点范围与口径

### 1.1 纳入范围

| 类别 | 示例 |
|------|------|
| 计算（集群内） | ACK/K8s 节点、Deployment/StatefulSet/Job、副本与 request/limit |
| 计算（集群外） | 独立 ECS、弹性伸缩组 |
| 存储 | 云盘、快照、NAS、对象存储（与服务强相关部分） |
| 数据与中间件 | RDS、Redis、MQ 等 |
| 网络 | SLB/ALB、弹性公网 IP、明显异常流量费用 |
| 环境 | 生产、预发、测试 |

### 1.2 暂不纳入（可后续单独立项）

- 与本组服务无关的共享平台摊销（除非账单挂在本组且可剥离）
- 人工成本、软件 License（非云资源）
- 一次性迁移/大促的临时扩容（进入例外清单并标注到期日）

### 1.3 成本口径

| 规则 | 说明 |
|------|------|
| 金额 | 优先使用项目**实付/折后** |
| 时间窗 | 默认「最近完整自然月」+「近 30 天」对照 |
| 基线月成本 | D7 用「最近完整自然月」账单合计冻结；取数接口人提供、牵头人确认；冻结后不因后续月份波动回溯修改 |
| 服务归因顺序 | ① 资源标签/项目 ② 实例名/命名空间 ③ Owner 人工确认 |
| 无法归因 | 进入「待归属池」，单独追踪，**不计入业务节约** |
| 浪费估算 | 建议节约金额 = 可关停全额 或 缩容/降配前后差价（写清假设） |
| 共享中间件 | 节约金额**只记在中间件评估卡一次**；业务服务卡可备注「受益于 xxx」，不得再加同一笔节约 |
| 已落地月节约入账 | 见 §7.2（观察窗口结束且未回滚，方可计入；账单偏差单独注明） |

### 1.4 服务定义

- **一张评估卡 = 一个可独立关停或改配的成本单元**（通常为一个业务服务在某一环境下的资源集合）。
- 同一服务多环境：拆成多张卡（如 `svc-a / prod`、`svc-a / test`）。
- 纯共享中间件：单独建卡，并注明分摊到哪些业务服务；节约不双计。

### 1.5 统一状态枚举

全文档（总览矩阵、评估卡、周报、回滚）只使用下列状态：

`待评估` / `待取数` / `方案已定` / `执行中` / `已完成` / `挂起-例外` / `挂起-待归属` / `挂起-有风险`

## 5. 动作分级与排期

### 5.0 P0 / P1 证据门槛（解决「监控未齐能否动」）

监控（序号 5）与流量（序号 6）**可以后补，但不等于可以无证据执行**。分级如下：

| 动作类型 | 环境 | 最低证据（满足其一组合即可） | 监控未齐时能否做 |
|----------|------|------------------------------|------------------|
| **P0 关停** | test / staging | ① 资源台账标明非生产 + Owner 书面确认「无业务用途」；或 ② 近 7 天流量/任务量为 0；或 ③ 创建者确认历史遗留 **且** Owner 确认 + 不在例外清单 | **可以**（优先用 ①；③ 必须带 Owner） |
| **P0 关停** | prod | 近 7 天流量/任务量为 0 **且** Owner + 依赖方确认 + 不在例外清单 | **不可以**（必须有流量/任务证据） |
| **P0 清挂账** | 任意 | 账单项目/标签与实际使用方不一致的证据 | **可以**（不依赖利用率） |
| **P1 缩容/降配** | 任意 | 利用率或规格对照证据（序号 5） | **不可以**，状态保持 `待取数` |
| **P2** | 任意 | 书面方案 + 评审通过 | 按评审材料 |

> 无流量证据时，生产实例不得以「感觉闲」关停；可先标 `待取数`，等序号 6 补齐再升级为 P0。

### 5.1 级别定义

| 级别 | 典型动作 | 风险 | 建议节奏 | 准入条件 |
|------|----------|------|----------|----------|
| **P0** | 确认闲置的非生产关停；生产无流量关停；明显挂错账拆清 | 低 | 第 1–2 周 | 满足 §5.0 对应证据门槛 + 不在例外清单 |
| **P1** | 缩副本、降规格、磁盘治理、测试定时开关机 | 中 | 第 2–3 周 | 满足 §5.0 P1 证据 + 回滚方式 |
| **P2** | 付费方式优化、服务合并、节点池整理、架构减配 | 中高 | 第 4 周起 | 书面方案评审通过 |

### 5.2 周节奏（组员执行）

1. 每人认领 N 张服务评估卡（同级内从高浪费项开始）。
2. 周会只同步三列：**本周关闭项 / 已确认节约金额 / 卡点**。
3. 卡点只允许归为：`要数据` / `要审批` / `有风险`，并写清下一步 Owner。分流：`要数据`→`待取数`；`要审批`（方案执行审批）→保持 `方案已定`；`要审批`（例外豁免/续期）→`挂起-例外`；`有风险`→`挂起-有风险`。
4. 「已落地月节约」仅在 §7.2 入账条件满足后回填，禁止变更当日用预估冒充已达成。

### 5.3 推荐执行顺序

```text
例外清单冻结
    → 最低可开工包取数 + 基线月成本冻结
    → 总览矩阵（先风险级、后浪费金额）
    → P0：非生产关停 / 清挂账（可无监控）
    → 补齐监控与流量后：生产无流量 P0 + 校准 P1
    → P1 缩容降配
    → P2 评审项
    → W2 末候选正式目标 → 月末冻结正式目标
```

## 6. 风险与回滚

### 6.1 变更前检查（生产必过）

- [ ] 评估卡已填完整（成本、证据、动作、回滚、验收）
- [ ] 不在例外清单，或已获书面豁免
- [ ] 依赖方已知晓（上游/下游 Owner）
- [ ] staging（或等价环境）已验证同类变更
- [ ] 回滚步骤可在约定时间内完成
- [ ] 观察窗口与值班人已明确（建议 ≥ 24h）

### 6.2 观察与回滚触发

| 现象 | 动作 |
|------|------|
| 错误率/失败任务明显上升 | 立即回滚，评估卡状态改为 `挂起-有风险` |
| 延迟显著恶化 | 暂停继续缩容，恢复至变更前，状态=`挂起-有风险`，并复盘 |
| 账单未按预期下降 | 核对是否删错资源或存在关联计费项；**不追溯改已确认节约**，在备注写明「账单偏差待查」，差额从下期核销 |

### 6.3 测试/预发简化路径

- 无业务约定的闲置资源：在满足 §5.0 非生产 P0 证据后可快速关停，仍需台账留痕。
- 定时开关机：先做 3–5 个工作日试点，再批量推广。
